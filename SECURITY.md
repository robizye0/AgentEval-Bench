# Security Policy

## Supported versions

Security fixes are provided for the latest released version. The `0.1.x` series is currently supported.

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting for this repository:

<https://github.com/robizye0/AgentEval-Bench/security/advisories/new>

Include the affected version or commit, steps to reproduce, and potential impact. Do not include live credentials, access tokens, or private user data in the report. We will acknowledge reports and coordinate a fix and disclosure with the reporter.
